# AI Office Suite

An AI-powered productivity platform designed to simplify everyday office tasks through a single web application. It provides tools for creating documents, presentations, spreadsheets, letters, and managing projects with AI assistance.

## Features

- **Dashboard:** Centralized workspace to access application modules.
- **AI Assistant:** AI-powered assistance for productivity tasks.
- **Documents:** Create and manage documents.
- **Presentations:** Create presentation content.
- **Spreadsheets:** Work with spreadsheet-related tasks.
- **Letters:** Prepare professional letters.
- **Projects:** Organize and manage projects.
- **Files:** Access and manage project files.

## Tech Stack

- React
- TypeScript
- Vite
- Node.js
- Google Gemini API

## Project Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd ai-office-suite
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

If required for AI functionality, create a `.env.local` file in the project root and configure your Gemini API key according to `.env.example`.

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Keep your API key private. Do not upload `.env.local` to GitHub.

### 5. Run the Application

```bash
npm run dev
```

### 6. Open in Browser

Visit:

```text
http://localhost:3000
```

The application runs locally using the development server.

## Running the Project

Keep the terminal open while using the application. To stop the development server, press `Ctrl + C` in the terminal.

## Purpose

The purpose of AI Office Suite is to bring multiple office productivity tools together in one platform and make everyday content creation and management easier with AI assistance.
